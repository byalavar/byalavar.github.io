DIAL: Label-Free Mitigation of Spurious Correlations in VLMs Using Sparse Autoencoders

B. C. Yalavarthi, N. Ratha, V. Govindaraju · ICLR 2026

Paper Code

The problem

CLIP-style models fail on specific groups because they lean on features that are correlated with the label in the training data but not causal for it — the water background instead of the bird, the imaging artifact instead of the lesion, gendered facial features instead of hair color. Existing fixes mostly require something the zero-shot setting is supposed to spare you: retraining, group labels, spurious-attribute labels, auxiliary data, or an LLM in the loop.

The idea

If a spurious feature is a direction in representation space, you should be able to find that direction and delete it — without ever seeing a label. DIAL does this in three steps:

  1. Disentangle. Pass VLM image embeddings through a pretrained sparse autoencoder to get a sparse, roughly monosemantic feature basis.
  2. Identify. Score each SAE feature by how much more it fires on samples exhibiting the spurious attribute (partitioned using the VLM's own zero-shot predictions as pseudo-labels), weighted by how well the feature direction aligns with the attribute's text embedding. Keep the features accounting for a fraction α of the total attribution mass.
  3. Label-free removal. Build an orthonormal basis for the spurious subspace and project it out of the affected embeddings — applied only to candidate samples flagged as likely biased (centroid distance + k-NN disagreement), so clean samples are left untouched.

DIAL+ removes the last remaining input: instead of being told which attributes are spurious, it finds them, by intersecting features whose ablation flips a prediction with the samples that look biased.

What it buys you

  • No training, no fine-tuning, no class labels, no spurious-feature labels, no auxiliary data, no external LLM.
  • Consistent worst-group accuracy gains across CelebA, Waterbirds, FMOW, ISIC, and COVID-19 — matching or beating baselines that do use labels and extra data.
  • Fairer image retrieval: MaxSkew@1000 on FairFace drops across age, gender, and ethnicity.
  • Every intervention is inspectable. You can name the feature you removed, which matters in high-stakes settings.

Two findings worth flagging

Orthogonal projection beats neuron ablation. Zeroing the identified activations leaves residual spurious structure behind; removing the whole subspace catches aligned features you never explicitly identified.

Selective intervention beats blanket intervention. Applying subspace removal globally degrades samples that weren't relying on the spurious feature in the first place. Targeting only flagged candidates recovers most of the gap (e.g. Waterbirds ViT-L/14: 51.6 → 69.2 worst-group).
